### What this implies about the prompts

This batch was not written to the prompts; it was extracted from docs that were written for the seat's own successor, who shares its vocabulary. So the finding is bounded: the next batch, written to `W/finalize.md`'s three prompts, may not have these defects. But the prompts as seeded do not prevent them either, and four of the five causes above are cheap to close at the prompt:

1. **Quote, do not cite.** A message, card or ruling named in a report is quoted (its first line, or the card title) because none of them survives the session. An id alone is testimony.
2. **Stamp the close.** Date, session, and the tree sha the report's last claim was measured at. The batch's single most repeated defect is a count with no sha (`R/retro.md:781-797` is the retro catching itself at it).
3. **Expand a house word the first time it appears in the report.** Not a glossary page (that is content, and anthill supplies the trigger), one parenthetical per word per report.
4. **Oldest first.** The report accretes during the session, so it is already chronological. The close prompts should not reorder it.
5. **Label the layer.** "I saw it in my pane / on the wire / on the board / in the tree" are four different evidence classes and the batch says so itself (`R/scout.md:87-89`, `R/retro.md:18-21`). One word per claim.

These are §5's W5 row. I do not propose changing `reports/README.md` yet; it points at the finalize page, which is the single source.

## 6. Proposed rulings for the curate page

To be added under `## Rulings` on `W/curate.md`, dated 2026-09-04, only if the human agrees with the row that forced each. Written so the next curator can apply them.

1. **A migration batch is not a report batch**, because it was extracted from docs written for a successor who shares the author's vocabulary, not written to the close prompts; it is triaged by class first, and a class's default destination is drop. (Forced by §2 and §3.)
2. **An epitaph is not a seat-doc reflex**, because an epitaph names a moment and its scar, and a reflex names a disposition that holds on every task; the disposition may enter Taste in one line and the scar goes to the report. (Forced by R-sentinel.)
3. **A contract's amendment history is not part of the contract**, because the contract states what is true across the boundary now; how it got that way is the report's, or the commit's. (Forced by R-seams, Contracts 1, 3, 4, 6.)
4. **A ratification record is not a contract clause**, because it is a fact about a session; it goes in the message of the commit that lands the seam. (Forced by R-seams, Contracts 6(g) and 7, and W3c.)
5. **A prose rule about how to write clauses is not a clause**, because it is a lesson wearing a contract's authority; if it generalises it is a principle, and if it is about this file it is one line in the preamble. (Forced by Contract 5(b) and the two authoring notes in Contract 4.)
6. **A limitation with a carded fix is not a seam**, because the fix will move the grain and there is no proof to pin; it is a backlog row until the fix lands. (Forced by R10a.)
7. **A stale line in a curated doc is curation's to change even when no report asked**, because curation is the only event that edits those docs and a report cannot be expected to audit a doc its author was told not to touch. (Forced by R1, R2, R8, and the four cleanups in R4.)
8. **A hypothesis with a falsifier is not a seat-doc line, a seam, or a principle**, because nothing curated is read at the moment it would be scored; until the C6 ledger exists it stays in the report and the lead's carry-forward names the ones the next session will test. (Forced by C6, 248 items, and W1c.)
