# Taxonomy — what kinds of thing do seats write down, and what would fix each kind?

Two blind passes and a comparison, 2026-09-03, run before the first curation so that curation's
first question — _what class is this?_ — starts from measured classes rather than guessed ones.

- [`pass-1-anthill/`](./pass-1-anthill/README.md) — anthill's own team: the migration report batch.
  1,392 items → 14 classes.
- [`pass-2-spellbook/`](./pass-2-spellbook/README.md) — Spellbook's team, whole docs + seams.
  2,006 items → 11 classes.
- [`COMPARISON.md`](./COMPARISON.md) — the alignment of the two, and a **common taxonomy of ten
  classes** covering 3,398 items, with the intervention shape both teams' sources converged on per
  class, and the three classes to route first.

**The headline, in both teams' own words.** Fourteen of fourteen classifiers concluded that a
recorded lesson does not fire for the agent who recorded it, and every intervention for the two
largest classes — claims that outran evidence (649 items), instruments that could not fail (479)
— is a tool that refuses at the moment of action, never more prose. Both teams also built a friction
log and then bypassed it.
