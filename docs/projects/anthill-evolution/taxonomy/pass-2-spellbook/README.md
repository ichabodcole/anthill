project that uses anthill, to test whether the classes are anthill's-team-specific or general.
Cole's expectation going in: "I have a feeling we'll find the same issues, but it's worth
confirming with a second project."

**Material.** Spellbook @ `e3d80dc` (2026-09-03): the five seat docs read **whole** (Spellbook is
not migrated, so identity sections are included — pass 1's material had them extracted), the
inter-seat contracts file `seams.md` (its own agent, because it is where Spellbook's lessons went),
and the retro, paper-cuts and principles files together. 6,448 lines.

one fresh merger over the seven outputs, also blind to pass 1. The comparison against pass 1 is a
separate step (`../COMPARISON.md`) and is the first place anything sees both.

**Files.** `MERGED.md` is the result; `source-<file>.md` are the seven blind passes.

**Numbers.** 2,006 items across 7 files. 65 source classes → 11 unified classes + 2 residue.
