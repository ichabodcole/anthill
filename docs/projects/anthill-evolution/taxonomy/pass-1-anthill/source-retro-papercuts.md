## Classes

Nine classes plus one unclassified bucket. Derived by asking, for each item, "what kind of thing did the authors write down?" rather than "what is it about?" — the same subject (e.g. counts rotting) appears as an incident, a hypothesis, a verdict and a principle candidate, and those are different kinds of record with different uses for a next session.

Temptations resisted: (1) merging HY and FU into one "prediction lifecycle" class — kept apart because a hypothesis is a claim and a verdict is an outcome record, and the useful question ("was it ever followed up?") is only answerable if they stay distinct; (2) merging RI into PD — the record-integrity notes are about this document's own trustworthiness and are read differently (as a discount on everything else) from a ritual defect; (3) splitting CD by mechanism (wrong count / wrong scope / wrong mechanism / fabricated / relay-widened) — the authors themselves propose that split in R241 and R134, but it is a split of causes, not of kinds, and the items would still all be "a named seat published a wrong statement and here is how it was caught"; (4) folding paper-cuts' dispositions (P2, P5, P7) into TD — they are outcome records of TD items, exactly as verdicts are of hypotheses, so FU.
